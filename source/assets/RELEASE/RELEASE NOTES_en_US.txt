RELEASE NOTES — OMNIFRAME 3D
Version: 2026.11.14.0
Date: November 14, 2026

Highlights of Version 2026.11.14.0:

1. New Interactive Guided Session (Help > Guided Session... or F2)
- Provides an automatic step-by-step demonstration of every feature in the application using any of the three built-in structural examples, with selectable reading paces designed for fluent reading, technical/engineering reading, reading aloud, or dyslexia-friendly reading.
- During playback, each active button, menu item, or input field is visually highlighted alongside a unified explanatory callout that adapts automatically to the active theme and language, stays clear of opened child windows, and holds each message for a duration proportional to its word count.
- When the Guided Session finishes or is closed, the selected example is automatically restored to its initial state.

2. Smoother and More Responsive Window Behavior
- All engineering dialogs now open immediately on a single click, eliminating the need for double-clicking and removing brief blank window flashes on screen.
- Child dialogs now operate smoothly alongside the main 3D workspace, preserving natural window stacking order as you switch between dialogs without pushing active panels behind the main window or locking the rest of the application.

3. Upgraded Side Inspector and Free Re-Editing of Built-In Examples
- The "Material:" and "Cross-Section:" dropdown lists inside the "Selected Element / Node" panel now open properly and display clean material and profile names without hashtag-number prefixes.
- You can now freely edit materials, cross-sections, supports, loads, combinations, member end releases, and recalculate any of the three built-in examples as a hands-on exercise before working on real projects, complete with Undo (Ctrl+Z), Redo (Ctrl+Y), and batch selection via "Same Material" and "Same Section".

4. Expanded Engineering Capabilities, Solvers & Reports
- Expanded structural modeling with thermal loads, load-combination and code-action assistants (dead, live, wind, and ABNT NBR guidance), a parametric mesh generator for 1D frames, 2D plates/shells, and 3D solids, J2 plasticity, and shear/corotational elements.
- New advanced analysis suite covering linear static, buckling, modal vibration, harmonic response, seismic response spectrum, second-order P-Delta effects, and material/geometric nonlinear analysis.
- Enhanced 3D post-processing with section clip planes, demand-to-capacity ratio (DCR) color maps, deformed and modal animations, plus an automated ABNT NBR verification dashboard.
- Broader export options including Executive A4 PDF calculation reports, CAD (DXF) and BIM (IFC4) import/export, and the dedicated command-line tool (omniframe-cli) included in external distribution packages.

5. Real-Time Language Switching, Themes & Updated Manual
- Every new window, label, callout, and control dynamically follows live language switching (Portuguese and English) and visual theme selection (Light, Dark, and High Contrast).
- Built-in Operations Manual (F1) and help documents updated in both Portuguese and English with detailed step-by-step guidance for all new capabilities.

RELEASE NOTES — OMNIFRAME 3D
Version: 2026.11.13.0
Date: November 13, 2026

Highlights of Version 2026.11.13.0 (Initial Production Release):

1. Computational Mechanics & 3D Finite Elements:
- Exact analytical formulation of 3D Euler-Bernoulli beam-column elements with 6 degrees of freedom per node (12 DOFs per element).
- 12x12 local stiffness matrix accounting for axial effects, Saint-Venant pure torsion, and bending about principal local y and z axes.
- 3D spatial rotation matrix with orientation by roll angle (psi).
- Continuous internal force recovery (N, Vy, Vz, T, My, Mz) along members utilizing Hermite cubic polynomials.
- Exact work-equivalent nodal load vectors for uniform distributed member loads, alongside concentrated nodal forces/moments, elastic springs, and prescribed displacements/rotations.
- Direct sparse Cholesky solver (SimplicialLDLT) via Eigen 3.4.0 with automated detection and graceful handling of singularities and structural mechanisms.

2. High-Performance 3D Viewport (OpenGL 3.3 Core):
- Modern GLSL 330 shader-based pipeline with Phong lighting.
- Interactive orbital 3D camera with smooth mouse navigation (right or middle-click orbit, Shift+drag pan, and wheel zoom).
- Simultaneous visualization of the undeformed geometry (neutral wireframe) and the amplified elastic deformed shape with continuous scaling factor control.
- Spatial entity picking mathematical algorithm via Raycasting (Eye-to-World ray cast) for accurate node and member selection in the viewport.
- Continuous color gradient rendering (spectral scale) for N, Vy, Vz, Tx, My, and Mz diagrams, plus support reaction vectors.

3. User Interface & Productivity (Qt 6.11.1):
- Modular docking panel system (QDockWidget), property inspector, and synchronized node and member tables.
- Parametric cross-section manager: solid rectangular, solid circular, hollow pipe, parallel-flange I/W steel sections, and generic sections.
- Pre-configured material database (Structural Steel ASTM A36 / MR250, Reinforced Concrete C25/C30, Aluminum 6061-T6, and Structural Timber C30) with custom material editor.
- Resilient persistence in open .omniframe (JSON) format with structural validation and technical report export to HTML and Markdown.

4. Distribution, Privacy & Dual Licensing:
- Dual licensing implemented: source code under GNU AGPLv3 for the GitHub community and official EULA for free distribution on the Microsoft Store.
- Build automation scripts for MSVC C++23 (CMake 3.28+), dedicated presets, and Inno Setup and MSIX packaging with clean uninstallation and 100% offline privacy.
- Comprehensive bilingual technical documentation (Portuguese and English) covering FEA fundamentals, standards comparison (NBR 8800, NBR 6118, AISC 360, Eurocode 3), and reference test cases.
