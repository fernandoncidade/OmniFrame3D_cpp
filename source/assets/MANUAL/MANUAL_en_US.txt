CHAPTER 1 — OVERVIEW, ARCHITECTURE, AND MODELESS WORKSPACE

1.1 Engineering Purpose and Scope
OmniFrame 3D is a free native Windows desktop application built with C++23, Qt 6, Eigen 3.4, and OpenGL 3.3 Core Profile that the user may use as they see fit as an auxiliary tool — for educational, academic, research, and result-comparison purposes — in interactive modeling, Finite Element Method (3D FEM) matrix stiffness analysis, and graphical post-processing of 3D space frames, grids, spatial trusses, shells, and solids.
Each structural node carries six degrees of freedom in 3D space (translations ux, uy, uz and rotations Rx, Ry, Rz), enabling analysis of members subjected simultaneously to axial force, biaxial shear, Saint-Venant torsion, and biaxial bending according to the exact Euler-Bernoulli beam-column formulation, alongside modal, linear buckling, spectral/harmonic/transient dynamics, and geometric and material nonlinearity (J2 Plasticity).
All mathematical computations and file persistence run 100% locally on the user's computer with zero telemetry, zero mandatory accounts, zero remote servers, and consistent International System units: meters (m) for coordinates and dimensions, kilonewtons (kN) for forces, kilonewton-meters (kN·m) for moments, kilonewtons per meter (kN/m) for distributed loads, gigapascals (GPa) for elastic moduli, degrees (°) for Roll orientation angles, and Celsius (°C) for thermal delta.

1.3 Main Window Anatomy (MainWindow)
The main window organizes the engineering workflow into six integrated, resizable workspace regions:
• Top Menu Bar: groups all commands across seven thematic menus (File, Edit, Examples, Structure, View, Settings, and Help).
• Toolbar 1 (Interaction, Work Plane & Views): provides cursor interaction tools (Select, Add Node, Add Member, Measure, Delete), Active Plane selector (XZ, XY, YZ), Elevation, Grid Step, Snap Grid, Local Axes, and quick standard views (3D Iso, Front, Plan, Side, Fit All).
• Toolbar 2 (Engineering, Analyses & Results): gathers assignment shortcuts (Materials, Sections, Supports, Hinges, Roll γ, Nodal Load, Dist. Load, Thermal ΔT), advanced engineering modules (Combinations, 2D/3D Mesh, Advanced, Clip/Contours, NBR Audit), RUN ANALYSIS (F5) button, Diagram selector, Reactions toggle, and visual Scale slider.
• Central OpenGL 3D Viewport: renders the three-dimensional structure, high-definition Active Plane, supports, concentrated forces, distributed loads, 2D/3D meshes, contour colormaps, 3D clipping planes, deformed shapes, internal force diagrams, and the viewport heads-up display (HUD) overlay.
• Left Dock Panel (Inspector & Quick Input): provides exact node insertion via Cartesian coordinates (X, Y, Z) together with the interactive Selected Element / Node panel featuring dropdown lists and direct editing buttons.
• Bottom Dock Panel (Result Tables & Structural Diagnostics) and Status Bar: displays four synchronized tabs for Nodal Displacements, Support Reactions, Member Forces, and 2D/3D Forces (Shell/Solid), while the status bar continuously reports live 3D cursor coordinates, node/member/mesh counters, and diagnostic status messages.

1.4 Dockable Panels (Docks), Lateral/Bottom Collapse, and Workspace Customization
Both the left panel and the bottom panel are dockable widgets (QDockWidget) that can remain docked along the main window edges or be detached into independent floating windows by dragging or double-clicking their title bar.
At any time, you can collapse, expand, toggle, or detach each panel to free screen area for the 3D Viewport without losing active selections or solved analysis results:
• Collapsing and Expanding "Inspector & Quick Input" (Left Side — Arrow ◀ / ▶): click the spin-button arrow pointing left (◀) in the header to collapse the inspector horizontally to the left edge as a compact vertical strip with its title label rotated 90° counterclockwise; click the arrow pointing right (▶) at the top of that vertical strip to expand the panel back to full width.
• Collapsing and Expanding "Result Tables & Structural Diagnostics" (Bottom — Arrow ▼ / ▲): click the spin-button arrow pointing down (▼) on the right side of the header to collapse the tables while keeping the full-width bottom title bar visible; click the arrow pointing up (▲) to restore all four results tabs.
• Floating Mode, Theme, Language, and Numeric Spinboxes: when either panel is floating, the same button collapses and expands the floating window cleanly while preserving compact behavior upon redocking; button tooltips ("Collapse panel" / "Expand panel"), rotated title, and arrows adapt live across Light/Dark themes and en-US/pt-BR languages, collapsed docks reopen automatically whenever Guided Session (F2) interacts with their controls, and all numeric input boxes render spin buttons whose outer corners follow the rounded control frame seamlessly.
• Resize Grip Handles, Compact Toolbars, and Native/Custom Modes: both the vertical Inspector splitter and horizontal Result Tables splitter display dotted drag handles in expanded and collapsed states; when a top toolbar overflows the window width, its extension button displays the tooltip "Expand or collapse hidden toolbar buttons", keeping every dock and control compatible with both Custom and Native modes under Settings > User Interface.
When a dock is floated as an independent window, it participates fully in visual layering management (Z-Order), allowing free focus switching among the floating dock, the main window, and any open child dialogs.

• Z-Order Stack and Raise on Click: the virtual Z-axis stack defines which window appears visually in front of the others on screen; clicking inside the client area or title bar of any active window (including the main window itself) immediately raises that window to the top of the Z-Order stack without involuntarily sending active child windows behind during normal interactions.

CHAPTER 2 — PROJECT MANAGEMENT, FILES, INTEROPERABILITY, AND EXAMPLES

2.1 New Project, Clean Startup, Session Recovery, and .omniframe Format
By default, the application starts with a completely empty workspace (with no preloaded model or previous results). Triggering File > New Project (Ctrl+N) resets the workspace after confirmation in a modeless dialog, while keeping full multi-level history under Edit > Undo (Ctrl+Z) and Redo (Ctrl+Y).
• Automatic Recovery Snapshot and Exit Protection: whenever you edit nodes, members, supports, loads, combinations, solver options, or wind metadata, a single atomic per-session recovery bundle (safely locked against collisions between multiple open windows) is automatically written under %LOCALAPPDATA%\OmniFrame\recovery\. Closing the application with unsaved edits presents a modeless confirmation dialog offering Save, Exit and Keep Recovery, or Cancel.
• Startup Policy (Previous Session): whenever a saved project, example, or unsaved edit remains from the previous session, the "Resume Previous Session" prompt lets you choose Load Previous Edit / Load Previous Project / Load Previous Example or Start New Project. This policy can be customized under Settings > Session, Startup and Logs (Ask on startup, Automatically load previous, or Always start a new project).
The native .omniframe format (Schema 2.1.0, backward-compatible with 1.0 and 2.0) uses human-readable UTF-8 JSON storing materials (including density ρ and J2 parameters), cross sections, nodes, elements, load combinations, and code-check settings with strict numerical validation rejecting non-finite values (NaN or infinity) on load.
WARNING: keep backup copies before editing .omniframe files manually in external text editors, preserving unique integer identifiers for nodes, materials, and cross sections.

2.2 Opening, Saving, Save As (.omniframe), Session Recovery, and CAD/BIM Exchange
To load an existing model, use File > Open (.omniframe)... (Ctrl+O) and pick the target file from the modeless file dialog (which automatically remembers the last used directory); upon loading, the window title displays the filename and the camera frames the entire structure.
To save changes to the active file, use File > Save (.omniframe) (Ctrl+S), or use File > Save As (.omniframe)... (Ctrl+Shift+S) to write to a new path; pending unsaved edits show the [*] modified indicator in the window title, and File > Recover Previous Session... restores the last recorded session from disk at any time.
Beyond the native format, the File menu offers four bidirectional, fully offline CAD and BIM interoperability tools:
• Import DXF... and Export DXF...: reads 3D wireframe lines and layers from CAD drawings (.dxf) with anti-DoS file-size bounds (128 MB default), strict finite-coordinate validation, and tolerance-based node merging, exporting structural members and faces (including surface meshes) back to DXF.
• Import BIM IFC4... and Export BIM IFC4...: imports open STEP IFC4 (.ifc) structural models reconstructing nodes, members, structural supports, and real shell thicknesses cleanly even when referenced nodes are missing, and exports the OmniFrame 3D model (including surface meshes) as IFC4 entities compatible with BIM platforms.

2.3 Calculation Report Export (HTML, Markdown, and A4 PDF)
The File menu provides three built-in exporters for engineering calculation documentation with zero external dependencies:
• Export Technical Report (HTML)...: generates a self-contained styled web report with formatted tables covering model summary, material and section inventory, global static equilibrium verification, nodal displacements, support reactions, and per-member action extremes.
• Export Technical Report (Markdown)...: generates a structured plain-text (.md) report compatible with Git version control, technical editors, and corporate documentation pipelines while preserving the exact solver verification metrics.
• Export Executive Report (A4 PDF)...: opens a configurable options dialog allowing you to include or omit the full ABNT NBR Code Compliance Audit, executive summary, displacement/reaction/force tables, and stability diagnostics, writing a print-ready A4 PDF directly to disk.
TIP: run the FEM solver (F5) or ABNT NBR Audit before exporting reports so that all tables, code checks, and global static equilibrium residuals reflect the latest results.

2.4 Built-in Structural Examples and Full Live Re-Editing Practice
The Examples menu includes three complete 3D structural models ready for immediate analysis, parametric study, and full live re-editing by the user:
• Example 1: 3D Building Space Frame (2 Stories, Wind and Live Load): multi-story concrete space frame with columns and beams subjected to combined vertical gravity and lateral loads.
• Example 2: L-Shaped 3D Cantilever under Bending-Torsion: plan L-bent cantilever beam clearly demonstrating torsion-bending coupling between orthogonal spans.
• Example 3: 3D Space Truss / Steel Footbridge: three-dimensional truss structure with released member ends (Tx, My, and Mz released), exhibiting predominantly axial tension and compression behavior.
When loading any of the three built-in examples, the Active Working Plane is set by default to XY (Plan) at elevation Z = 0.00 m and the camera frames the entire structure automatically.
All three built-in examples remain fully editable once loaded: you can select nodes or members in the viewport, switch materials and cross sections directly in the side inspector dropdown lists, modify coordinates, supports, loads, or combinations, apply Undo/Redo (Ctrl+Z / Ctrl+Y), and re-solve immediately (F5) as hands-on practice for study, learning, and result comparison.

CHAPTER 3 — 3D NAVIGATION, ACTIVE PLANE, AND VISUALIZATION

3.1 3D Orbital Camera and Standard Views
Three-dimensional navigation combines direct mouse controls in the 3D Viewport with quick standard orientation buttons:
• Orbit (Free Rotation): hold the Right or Middle mouse button and drag across the viewport to orbit around the scene target pivot.
• Pan (Lateral Translation): hold the Shift key while dragging with the Right or Middle mouse button to shift the view parallel to the screen plane.
• Smooth Zoom: rotate the mouse scroll wheel to zoom in toward or out from the model smoothly.
• Standard Views and Framing: use the View menu or toolbar view buttons to switch immediately between 3D Isometric View (3D Iso), Front View (XZ) (Front), Plan View (XY) (Plan), or Side View (YZ) (Side), or trigger Fit All (F) / Fit View (F) to frame the entire structure inside the viewport.

3.2 Active Working Plane (XY, XZ, YZ) and Offset
To sketch nodes accurately in 3D space using a two-dimensional mouse cursor, OmniFrame 3D casts a geometric picking ray from the camera onto the selected Active Working Plane.
• XZ Plane (Front): ideal for constructing vertical planar frames and building elevations along a constant Y coordinate.
• XY Plane (Plan): ideal for constructing floor plans, horizontal grids, and slabs at a fixed Z elevation (default active plane selected at startup and when loading the three built-in examples).
• YZ Plane (Side): ideal for constructing transverse frames and elevations perpendicular to the global X axis.
• Active Plane Elevation (Elevation:): the numerical elevation control shifts the working plane parallel to its normal axis (for example, Z = 3.00 m when modeling a second-floor deck).

3.3 Dynamic Grid and Precision Snap
The spatial grid renders subtle minor subdivisions and accentuated major lines spaced by the configurable Step: field (in meters).
When Snap Grid is enabled, coordinates picked on the active plane automatically round to the nearest exact multiple of the configured grid step, accompanied by a live preview marker showing the snapped point beneath the cursor prior to clicking.
NOTE: grid borders, grid lines, and axes are rendered with analytical subpixel shaders combined with MSAA and supersampling so lines remain sharp even at grazing camera angles.

3.4 3D Selection (Raycasting) and Visual Highlight
In Select (S) mode, a single left click performs geometric raycasting against nodes (with a priority screen tolerance radius) and structural members.
Selected nodes highlight in cyan with an enlarged sphere and selected members are drawn thicker in cyan highlight, immediately synchronizing both the Inspector & Quick Input dock and the active row in the Result Tables & Structural Diagnostics dock.
Holding Ctrl while clicking toggles or builds multi-selections of nodes and members for batch property assignment; clicking empty space or pressing Esc clears the active selection.

3.5 Member Local Axes and Graphical Symbols
Enabling Local Axes draws the right-handed orthogonal triad (x, y, z) at the midpoint of each element: red marks longitudinal local x from start node i to end node j, green marks principal local axis y, and blue marks principal local axis z.
Graphical symbol legend across the 3D scene:
• Fixed Support: solid blue cube anchored beneath the restrained node.
• Pinned Support: green 3D pyramid with its apex meeting the node.
• Roller Support: amber/orange pyramid supporting the node.
• Nodal and Distributed Loads: red arrows indicate concentrated nodal forces; continuous rows of green arrows along members indicate distributed loads; cyan double arrows represent applied moments or moment reactions.

CHAPTER 4 — GEOMETRIC MODELING, SIDE INSPECTOR, AND MESH GENERATOR

4.1 Adding Nodes on the Active Plane and via Numerical Input
Two complementary methods allow you to create structural nodes accurately:
• Interactive Click (Add Node (N)): activate Add Node (N) on the toolbar (or press N), hover across the Active Working Plane while monitoring live coordinates on the status bar, and left-click to place the node immediately with optional Snap Grid.
• Exact Numerical Input (Left Dock): type exact Cartesian coordinates X, Y, and Z into the Add Node by Coordinates group inside the Inspector & Quick Input dock and insert the node, ideal for fractional dimensions or nodes located off the current working plane.

4.2 Connecting Members between Nodes
To connect two existing nodes with a frame/truss member, activate the Add Member (B) tool (or press B).
Left-click the start node (node i) first and then left-click the end node (node j); the created member automatically adopts the default material and cross section with an initial Roll angle of 0°.
NOTE: clicking the same start node twice or clicking empty space without a valid node prevents zero-length degenerate elements; press Esc at any time to cancel an in-progress member link.

4.3 Spatial Measurement Tool (ΔX, ΔY, ΔZ, L)
The Measure (M) tool lets you inspect clear spans, story heights, and diagonal distances without modifying the structural model.
With Measure (M) mode active, click the first point or reference node and then click the second point; the status bar reports total Euclidean length L along with orthogonal global deltas ΔX, ΔY, and ΔZ in meters.

4.4 Safe Deletion and Selection Clearing
To delete unwanted entities, select one or more nodes or members in the viewport and trigger Delete (Del) (Del key or the corresponding toolbar button).
Deleting a node automatically removes all members attached to it as well as associated rigid links/diaphragms, loads, and selection references so the structural mesh remains topologically valid without dangling references; any deletion can be reverted cleanly via Edit > Undo (Ctrl+Z).
Pressing Esc exits active chained creation modes or clears the current selection cleanly.

4.5 Side Property Inspector (Selected Element / Node) and Batch Selection
Clicking any node or member in the 3D Viewport (or holding Ctrl for multi-selection) populates the Selected Element / Node panel on the left dock with direct inline editing controls for the current selection:
• When one or more nodes are selected: lets you edit X, Y, and Z coordinates directly, apply batch coordinate offsets/increments (ΔX, ΔY, ΔZ), edit Support Conditions and Concentrated Nodal Loads via quick action buttons, and apply changes to the model with optional automatic re-solve.
• When one or more members are selected: provides clean Material: and Cross-Section: dropdown comboboxes displaying clean catalog names (without numeric hash prefixes) — clicking the arrow or field opens the full list immediately to reassign all selected members — alongside quick edit buttons for Roll (γ), Hinges, Distributed Load, and Thermal Load (ΔT).
• Quick Criteria Selection: the Same Material and Same Section buttons automatically select every member in the model sharing the active member's material or cross section, streamlining batch adjustments across both new models and the three built-in examples.

4.6 Parametric 1D/2D/3D Mesh Generator (Shells and Solids)
Open Structure > 1D/2D/3D Mesh Generator... (or 2D/3D Mesh... on Toolbar 2) to generate and couple surface or volumetric finite element meshes anywhere in your project with an integrated end-to-end (E2E) workflow:
• Supported Element Families (Mesh Type:): generates refined 1D lines (Line2), 2D shell/plate meshes (2D Structured Quad4 Slab/Shell, 2D Quadratic Quad8 Slab/Shell, Structured Tri3, and Delaunay Tri3 Polygon) for slabs, walls, and shells, 3D solid blocks (Structured Hex8, Quadratic Hex20, and Structured Tet4), and 2D -> 3D Hex8 Extrusion.
• Material, Thickness, Supports, and Dimension-Aware Load: choose Mesh Material: from the project catalog, set Thickness (2D Shell): in meters, pick a ready Constraint Condition: preset (including proper bottom-base Zmin restraint for 3D solids without over-restraining all 6 faces), and enter loads in the unit matching the mesh dimension — Linear Z Load (1D) in kN/m, Normal Pressure / Z Load (2D) in kPa, or Body Force / Volumetric Z Load (3D) in kN/m³ (2D -> 3D extrusion validates and requires a Tri3/Quad4 base mesh).
• Automatic Bounding-Box Fitting and Dimensions: enter Origin (X / Y / Z), Dimensions (Lx / Ly / Lz), Subdivisions (nx / ny / nz), and Delaunay target size, or click Fit to Model Bounds to adapt the generator box automatically to the active frame bounds.
• Quality Diagnostics, Coupling, and Cleanup: displays node/element counts and quality metrics (J_min, Aspect ratio range, and max Skewness); running SOLVE STRUCTURE (F5) automatically merges coincident 1D and 2D/3D nodes (while pure solid nodes allocate only 3 translational DOFs uX, uY, uZ) and populates the 2D/3D Forces (Shell/Solid) tab. Use Clear Mesh to remove the parametric 2D/3D mesh cleanly while keeping the primary 3D frame intact.

CHAPTER 5 — STRUCTURAL PROPERTIES, BOUNDARY CONDITIONS, THERMAL LOADS, AND COMBINATIONS

5.1 Isotropic Material Library and J2 Plasticity
Open Structure > Materials... (or click Materials... on the toolbar) to open the modeless material editor where you can create, edit, or select materials defined by their physical constants: Longitudinal Elastic Modulus E (GPa), Poisson's Ratio ν, Thermal Expansion Coefficient α (/°C), Specific Weight γ (kN/m³), and Mass Density ρ.
Four ready-to-use engineering presets are included: Structural Steel (ASTM A36) (E = 200 GPa, ν = 0.30, γ = 78.5 kN/m³), Structural Concrete C30 (E = 30 GPa, ν = 0.20, γ = 25.0 kN/m³), Aluminum 6061-T6 (E = 70 GPa, ν = 0.33, γ = 27.0 kN/m³), and Structural Timber (E = 14.5 GPa, ν = 0.20, γ = 8.0 kN/m³).
When enabled for elastoplastic nonlinear analyses, materials also store yield stress σy (MPa) plus isotropic (H_iso) and kinematic (H_kin) hardening moduli for the von Mises J2 Plasticity constitutive model.
Confirming with members selected in the 3D viewport assigns the chosen material to all selected members immediately without interrupting your modeling workflow; materials currently assigned to 2D/3D continuum mesh elements are also protected against accidental deletion.

5.2 Cross Sections and Automatic Inertia Calculation
Open Structure > Cross Sections... (or Sections... on the toolbar) to configure member cross-section geometry using analytical shape families in meters (m), m², and m⁴:
• Rectangular: specify width b (along local y) and height h (along local z).
• Circular Solid: specify outer diameter D.
• Circular Tube: specify outer diameter D_ext and wall thickness t.
• Rolled or Welded I-Profile: specify total depth h, flange width b_f, flange thickness t_f, and web thickness t_w.
• Generic (Manual), Custom Polygon and Composite Section: direct entry of A, Iy, Iz, and J alongside preserved dialog support for Custom Polygon and Composite Section families (plus steel shapes such as Angle L, Channel U, and Asymmetric I-Profile).
Computed sectional properties (A, Iy, Iz, and J) are dynamically validated against invalid wall, flange, web, or leg dimensions and displayed for verification before batch assignment to selected members.

5.3 Nodal Supports, Elastic Springs, and Prescribed Settlements
Open Structure > Support Conditions... (or Supports... on the toolbar) with one or more nodes selected to configure each of the six global degrees of freedom (uX, uY, uZ, θX, θY, θZ) individually.
Quick presets include Fixed (all 6 DOFs restrained), Pinned Support (uX, uY, uZ restrained and rotations free), Roller Support (Z) (vertical uZ restrained only), and Free (clears all restraints), alongside optional elastic spring stiffnesses (0 to 1×10⁹ kN/m or kN·m/rad) and prescribed support displacements or rotations (±100) on any active DOF.

5.4 Member End Releases (Internal Hinges)
Open Structure > Hinges / End Releases... (or Hinges... on the toolbar) to model pinned connections or pure truss bars by releasing individual DOFs at the start node (i) or end node (j) of selected members.
Preset buttons switch rapidly between Fixed-Fixed (standard rigid frame connection), Start Hinge (releases bending moments at start node), End Hinge (releases bending moments at end node), and Truss Member (releases Tx, My, and Mz at both ends).
Internally, the solver performs exact static condensation on the 12×12 local stiffness matrix before global transformation.

5.5 Section Orientation via Roll Angle (γ)
Open Structure > Section Roll Angle (γ)... (or Roll (γ)... on the toolbar) to rotate principal local axes y and z around the member's longitudinal x axis within the range -360° to +360°.
For inclined or horizontal members at Roll = 0°, local axis z points toward the upper vertical half-space (vertical local xz plane); for strictly vertical columns (parallel to global Z), the local basis automatically applies a singularity-free reference direction combined with the requested γ angle.
Turn on Local Axes in the viewport to verify flange and principal-axis orientation visually as soon as Roll (γ) changes are applied.

5.6 Concentrated Nodal Loads (Forces and Moments)
Open Structure > Concentrated Nodal Loads... (or Nodal Load... on the toolbar) with one or more nodes selected to apply concentrated global forces (Fx, Fy, Fz in kN) and concentrated global moments (Mx, My, Mz in kN·m).
Under OmniFrame 3D's standard global coordinate convention, gravity acts in the negative Z direction (-Z), so downward vertical gravity forces use negative Fz values (for instance, Fz = -50 kN).
To remove nodal loads from selected nodes, set all components to zero or reset the inputs and apply to the selected nodes.

5.7 Distributed Member Loads (Global and Local)
Open Structure > Uniformly Distributed Loads... (or Dist. Load... on the toolbar) with one or more members selected to define uniform distributed loads qx, qy, and qz in kN/m along the full member span (default initial value qz = -10.0 kN/m).
Select Global System (X, Y, Z) (loads aligned with project X, Y, Z axes, suited to gravity and dead loads) or Member Local System (x, y, z) (loads aligned with the member's own local x, y, z axes, suited to wind pressure or normal roof loads).
The solver automatically transforms distributed loads and recorded thermal variations into exact equivalent nodal Fixed-End Force vectors.

5.8 Uniform and Gradient Thermal Loads (ΔT)
Open Structure > Thermal Loads (ΔT)... (or Thermal (ΔT)... on Toolbar 2) with one or more members selected to assign uniform temperature variation ΔT (°C) and optional transverse thermal gradients along the member's local axes.
Using the thermal expansion coefficient α configured on the member material, the solver automatically computes exact fixed-end axial forces and thermal moments in indeterminate frames or free thermal elongation in statically determinate spans.

5.9 Load Cases, ABNT NBR Combinations & 6120/6123 Assistants
Open Structure > Load Cases, NBR Combinations & Wind... (or Combinations... on Toolbar 2) to manage multiple load cases (Dead G, Live Q, Wind W, Thermal T, Seismic E) and factored combinations:
• Automatic ABNT NBR Combinations: the Generate NBR Combinations button captures active viewport loads when needed and generates standard combinations (ULS-1 Normal, ULS-2 P-Delta — automatically enabling real iterative P-Delta analysis — and SLS Quasi-Permanent with ψ2 = 0 for seismic loads), alongside custom entries via + New Combination.
• Engineering Code Assistants: dedicated tabs assist in estimating basic/characteristic wind speed and stagnation pressure under ABNT NBR 6123:2023 (V0, S1, S2, S3) and reviewing occupancy live-load parameters under ABNT NBR 6120:2019.

CHAPTER 6 — FINITE ELEMENT ANALYSIS, ADVANCED SUITE, AND NBR AUDIT

6.1 Model Pre-Validation and Mechanism Detection
Before assembling the linear system, the model undergoes validate() structural checks verifying sufficient nodes and elements, support restraints preventing rigid-body motion, valid material/section references, and strictly positive member lengths and mechanical moduli.
If the model contains kinematic mechanisms, global under-restraint, or a non-positive-definite stiffness matrix, the solver halts safely and displays a diagnostic message inside a modeless alert window identifying the probable cause.

6.2 Matrix Formulation and Sparse Solver Suite (LinearSolverSuite)
Triggering Structure > RUN ANALYSIS (F5 key or the ▶ RUN ANALYSIS (F5) toolbar button) launches FemSolver3D via the unified asynchronous executor (running real iterative P-Delta when enabled) on a background worker thread without freezing the UI, enforcing mutual exclusion between F5 and the Advanced Suite, cooperative cancellation, and automatic discard of stale results if the model changes mid-solve:
1. Computation of the exact 12×12 local member stiffness matrix including axial (EA/L), torsional (GJ/L), and biaxial Euler-Bernoulli bending (12EI/L³, 6EI/L², 4EI/L, 2EI/L) stiffness terms plus static condensation for end releases and 2D/3D shell/solid elements when an active mesh exists.
2. Orthogonal transformation to global coordinates via block matrix [T] = diag(R, R, R, R) using K_glob = T^T · K_loc · T and fixed-end force vector transformation (covering self-weight, distributed loads, and thermal ΔT).
3. Global sparse stiffness matrix assembly incorporating elastic spring stiffnesses, support restraints, and prescribed displacements.
4. Direct or iterative resolution via LinearSolverSuite — SimplicialLDLT with AMD fill-reducing ordering (default), SimplicialLLT, SparseLU, ConjugateGradient, or BiCGSTAB — reporting total solve time in milliseconds.

6.3 Global Static Equilibrium Verification
Immediately after solving nodal displacements {u} and recovering local end forces and global support reactions {R}, the solver sums applied force and moment resultants against support reaction resultants.
Residual force errors (ΔFx, ΔFy, ΔFz) and residual moment errors about the origin (ΔMx, ΔMy, ΔMz) are automatically audited in EquilibriumCheck and embedded into both HTML/Markdown/PDF calculation reports and analysis summaries.

10.6 Complete Reference of Analysis, Solver, Nonlinear, and Dynamic Options
• --analysis <type>: selects the finite element analysis solver — accepted values: static (default), modal, buckling, nonlinear, pdelta, harmonic, spectrum, transient, or seismic.
• --solver <type>: selects or auto-routes the sparse linear equation solver from LinearSolverSuite — auto (default, tracks fallback if triggered), ldlt (SimplicialLDLT), llt (SimplicialLLT), sparselu (SparseLU), cg (ConjugateGradient), or bicgstab (BiCGSTAB).
• --modes <N>: number of eigenvalues/eigenvectors for modal, buckling, or spectrum analysis (integer >= 1; default: 6).
• --steps <N>: number of load increments for nonlinear/pdelta or time integration steps for transient/seismic (integer >= 1; default: 20).
• --dt <seconds>: time step size in seconds for transient or seismic integration (minimum: 0.00001 s; default: 0.02 s).
• --scheme <newmark|hht>: chooses the implicit time-integration scheme for transient or seismic — newmark (average-acceleration Newmark-beta, default) or hht (Hilber-Hughes-Taylor HHT-alpha).
• --case <id>: selects an integer LoadCase ID for static or transient analysis.
• --combo <id>: selects an integer ABNT LoadCombination ID for static analysis.
• --method <nr|arclength>: selects the incremental-iterative nonlinear strategy — nr (Newton-Raphson, default) or arclength (Crisfield cylindrical Arc-Length).
• --load-factor <factor>: sets target load multiplier for nonlinear and pdelta analysis (default: 1.0).
• --full-tangent: updates global tangent stiffness matrix Kt at every Newton-Raphson iteration (Full Newton-Raphson, default).
• --modified-newton: freezes tangent stiffness Kt within each load step (Modified Newton).
• --line-search: enables backtracking line search during Newton-Raphson equilibrium iterations (default).
• --no-line-search: disables line search during Newton-Raphson iterations.
• --imperfection <amp_m>: pre-runs linear buckling and perturbs initial nodal geometry along the chosen buckling mode shape scaled to the specified amplitude in meters (e.g., 0.005 for 5 mm) prior to solving/exporting (requires a model with valid positive buckling load factors).
• --imperfection-mode <N>: selects the 1-based buckling mode index used by --imperfection (default: 1).

10.7 Export Formats, Engineering Reports, JSON Schema, and Exit Codes
• --export <fmt> <path>: exports model geometry and/or computed results to disk (repeatable in a single command for multiple formats). Supported formats: json (serialized .omniframe project including displacements and stresses), csv (nodal displacements plus continuum shell/solid stress table), vtk (legacy VTK UNSTRUCTURED_GRID 1D/2D/3D with nodal displacement vectors and cell von_mises_kPa for ParaView), dxf (3D CAD interchange preserving surfaceMesh meshes), and ifc (IFC4 structural BIM interchange preserving surfaceMesh, supports, and real shell thickness).
• --report <fmt> <path>: generates engineering calculation reports in md (Markdown), html (styled HTML5), or pdf (A4 technical calculation report). Repeatable in one call; automatically embeds static, modal, buckling, and nonlinear solver results plus ABNT NBR audit tables when available.
• --output <path.json>: writes the full indented JSON analysis summary cleanly to disk (works with or without --json on stdout).
• --json: prints the complete indented JSON summary object to stdout.
• Primary JSON output keys: schemaVersion, inputFile, exampleName, analysisType, valid, nodes, elements, surfaceNodes, surfaceElements, validationErrors, validationWarnings, validationIssues, success, and error; plus solver-specific metrics (maxNodalDisplacement, totalStrainEnergy, relativeResidual, usedFallback, solverMessage, equilibriumBalanced, frequenciesHz, criticalLoadFactors, appliedImperfection, totalSteps, totalIterations, finalLoadFactor, fullNewtonTangent, enableLineSearch, anyYielded, scheme, dt, peakDispNorm, nbrAudit, and Windows integration diagnostics readyForCmdAndPowerShell / PATH / App Paths flags).
• Process exit codes (Exit Codes):
1. Code 0: clean success (query command succeeded, model passed validation, solver converged, and all requested exports/reports were written).
2. Code 1: CLI syntax error, invalid or non-finite numeric argument (NaN/Inf flags are strictly rejected while still emitting valid JSON errors when --json or --output is active), missing/unreadable input file, unknown format, or disk/Windows registry write failure.
3. Code 2: structural model validation failure (--validate) or numerical/physical solver failure (mechanism, singular stiffness, lack of positive buckling modes for --imperfection, or nonlinear non-convergence).
